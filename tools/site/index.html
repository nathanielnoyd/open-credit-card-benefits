Open Credit Card Benefits

Structured, sourced data on US credit card benefits: fees, earn rates, statement credits, lounges, protections, points and transfer partners, with dated history.

Data

  • llms.txtStart here if you're an AI agent
  • cards.jsonEvery card with its fee, summary and file links
  • catalog.jsonThe full catalog in one file
  • releases.jsonEvery dated change in terms, newest first
  • glossary.jsonWhat every kind, category, condition and currency means
  • index.jsonCatalog version and the list of every published file

Use it in code

npm install github:nathanielnoyd/open-credit-card-benefits

The package includes a TypeScript engine for resolving card terms and valuing a wallet. Documentation is on GitHub.

Compiled from issuer pages and published reviews. This isn't issuer terms or financial advice; check with the issuer before relying on a figure.
